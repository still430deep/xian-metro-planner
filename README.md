# 西安地铁路线查询网站

项目核心及服务端逻辑使用 Python 标准库。网页模板和 CSS 负责手机浏览器呈现；不含 JavaScript 程序代码，也不需要安装第三方 Python 包。

## 启动

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py server.py
```

浏览器访问 `http://127.0.0.1:8000`。同一 Wi-Fi 下手机可访问电脑的局域网 IP 和端口 8000。

## 当前数据口径

`data/network.json` 的线路站序依据 MetroMan 西安车站清单整理，包含 1–10、14–16 号线及西户线。相邻站距离按线路公开总里程均分估算；行车时间按线路全程时间均分，换乘暂加 4 分钟。普通线路票价按里程阶梯计算；仅全程乘坐 8 号线时应用 6 元全程票价。估算值均在页面说明，后续可用官方区间数据替换。
